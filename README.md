# Forge Builder Blog

Static blog hosted on GitHub Pages.

- `index.html` — landing page listing all posts
- `posts/` — one self-contained HTML file per post

## Adding a post

1. Drop the HTML file into `posts/` with a URL-safe name (lowercase, hyphens, no spaces).
2. Add a matching `<li class="post">` card to `index.html`.

## Publishing

In the GitHub repo: **Settings → Pages → Build and deployment → Deploy from a branch**, choose `main` and `/ (root)`.
